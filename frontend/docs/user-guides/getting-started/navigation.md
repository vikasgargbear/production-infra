# 🧭 Understanding the Menu

> Navigate the application efficiently with this menu guide.

---

## Main Navigation

The menu is located on the left side of the screen (or top on mobile).

---

## Menu Items

### 📊 Dashboard
Your home screen with business overview, key metrics, and quick actions.

---

### 💼 Sales
Everything related to selling:

| Menu Item | What it Does |
|-----------|--------------|
| **New Invoice** | Create a sales invoice |
| **Invoice History** | View past invoices |
| **Sales Orders** | Manage customer orders |
| **Delivery Challan** | Send goods without invoice |
| **Sales Returns** | Process customer returns |
| **Outstanding** | Track pending payments |

---

### 🛒 Purchase
Managing your purchases:

| Menu Item | What it Does |
|-----------|--------------|
| **New Purchase** | Create purchase order |
| **Purchase History** | View past purchases |
| **Receive Goods (GRN)** | Record incoming stock |
| **Purchase Returns** | Return to supplier |
| **Supplier Outstanding** | Track what you owe |

---

### 📦 Inventory
Stock and product management:

| Menu Item | What it Does |
|-----------|--------------|
| **Current Stock** | View all stock levels |
| **Products** | Manage product catalog |
| **Add Product** | Create new product |
| **Stock Adjustments** | Correct stock levels |
| **Expiring Soon** | Items near expiry |

---

### 👥 Customers
Customer management:

| Menu Item | What it Does |
|-----------|--------------|
| **Customer List** | View all customers |
| **Add Customer** | Create new customer |
| **Customer Ledger** | Transaction history |

---

### 🏭 Suppliers
Supplier management:

| Menu Item | What it Does |
|-----------|--------------|
| **Supplier List** | View all suppliers |
| **Add Supplier** | Create new supplier |
| **Supplier Ledger** | Transaction history |

---

### 📈 Reports
Business insights:

| Menu Item | What it Does |
|-----------|--------------|
| **Sales Report** | Analyze sales |
| **Purchase Report** | Purchase analysis |
| **Stock Report** | Inventory insights |
| **GST Reports** | Tax compliance |
| **Outstanding Report** | Receivables/Payables |

---

### ⚙️ Settings
Configure the app:

| Menu Item | What it Does |
|-----------|--------------|
| **Company Profile** | Business details |
| **User Management** | Add/manage users |
| **Invoice Settings** | Customize invoices |
| **Tax Settings** | GST configuration |
| **Print Templates** | Print layouts |

---

## Quick Tips

### Keyboard Shortcuts
- Press `/` to focus search bar
- Press `Ctrl + /` to see all shortcuts

### Collapsing Menu
- Click the hamburger icon (☰) to collapse
- Gives more screen space

### Search Bar
- Search anything: products, customers, invoices
- Just start typing!

# 🖨️ Print Issues

> Solutions for common printing problems.

---

## Print Preview Not Loading

### Try These Steps
1. Wait 10-15 seconds for loading
2. Refresh the page (F5)
3. Clear browser cache
4. Try a different browser
5. Check internet connection

---

## Nothing Prints

### Check Printer Basics
1. Is printer turned on?
2. Is printer connected (USB/WiFi)?
3. Is there paper?
4. Is there ink/toner?

### Test Your Printer
1. Print a test page from your computer
2. If test fails, fix printer settings first

### Check Browser Settings
1. Make sure pop-ups aren't blocked
2. Allow printing from the site

---

## Wrong Layout / Size

### Paper Size Mismatch
1. Go to **Settings → Print Templates**
2. Select correct paper size
3. Thermal printers: 2" or 3"
4. Regular printers: A4 or A5

### Scaling Issues
In browser print dialog:
1. Set scale to **100%** (not "Fit")
2. Set correct paper size
3. Check margins (usually "Default")

---

## Text/Layout Cut Off

### Set Correct Margins
1. In print dialog, check margins
2. Use "Default" or "Minimum" margins
3. Don't use "None" (content may cut off)

### Check Paper Size
- Paper in printer must match template size
- A4 template → A4 paper

---

## Logo Not Printing

1. Ensure logo is uploaded in **Company Profile**
2. Check if logo is enabled in **Print Templates**
3. Try re-uploading logo (PNG format, max 500KB)

---

## Print Quality Poor

### For Thermal Printers
- Use correct thermal paper
- Clean printer head
- Check printer density settings

### For Inkjet/Laser
- Check ink/toner levels
- Run printer cleaning
- Use quality paper

---

## Barcode Not Scanning

If printed barcode won't scan:
1. Increase print quality
2. Make sure barcode is big enough
3. Don't stretch barcode disproportionally
4. Clean scanner lens

---

## Printing Takes Too Long

1. Reduce data in print (shorter notes)
2. Check printer queue - clear stuck jobs
3. Restart printer spooler service
4. Try different browser

# 🔐 Login Issues

> Solutions for common login problems.

---

## Can't Log In

### "Invalid username or password"

**Try these steps**:
1. Check spelling of username/email
2. Ensure Caps Lock is off
3. Try typing password in a text editor first to verify
4. Clear browser autofill and type manually

**Still not working?**
Use "Forgot Password" to reset

---

### Forgot Password

1. Click **Forgot Password** on login page
2. Enter your registered email or phone
3. You'll receive:
   - Email with reset link, OR
   - SMS with OTP
4. Create a new password
5. Log in with new password

---

### Account Locked

**Why it happens**: Too many failed login attempts (security).

**Solution**:
1. Wait 15-30 minutes for automatic unlock
2. Or contact your admin to unlock
3. Or use Forgot Password

---

### Session Expired

**Why it happens**: Inactive for too long.

**Solution**:
- Simply log in again
- This is normal security behavior
- Save work frequently to avoid data loss

---

## Browser Issues

### "Page not loading"

1. Refresh the page
2. Clear browser cache (Ctrl+Shift+Delete)
3. Try incognito/private mode
4. Try a different browser

### "Keeps logging me out"

1. Check if cookies are enabled
2. Clear browser cache
3. Disable browser extensions temporarily
4. Check your internet connection

---

## Account Issues

### "Account not found"

- Verify you're using correct login URL
- Check with admin if account was created
- Try email instead of username (or vice versa)

### "Access denied" after login

- Your account may be deactivated
- Your role may not have access
- Contact admin for permissions

---

## Multi-Device Login

### "Logged out on other device"

Some accounts allow only one active session:
- Logging in on new device logs out old one
- This is for security
- Contact admin if you need multi-device

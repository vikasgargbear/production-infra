# 🔄 Sync Issues

> Solutions for data synchronization problems.

---

## Recognizing Sync Issues

You might have sync issues if:
- "Offline" indicator shows
- Data seems outdated
- Changes not saving
- Other users don't see your updates

---

## Quick Fixes

### Step 1: Check Internet
1. Open any website (google.com)
2. If that doesn't work, fix internet first

### Step 2: Manual Sync
1. Click the **Sync** icon (usually near user menu)
2. Wait for sync to complete
3. Check if data is updated

### Step 3: Refresh Page
1. Press F5 or click refresh
2. Wait for full load
3. Check your data

---

## "Offline Mode" Showing

**Why it happens**: No internet connection detected.

**Solutions**:
1. Check WiFi/network connection
2. Check if other sites work
3. Restart router if needed
4. Wait and retry

**Working Offline**:
- You can still create invoices
- Data syncs when back online
- Don't log out while offline

---

## Data Not Saving

**When you save but it doesn't stick**:

1. Check for error messages
2. Don't navigate away too quickly
3. Wait for "Saved" confirmation
4. Check internet connection
5. Try saving again

---

## Other Users Don't See My Changes

**Possible causes**:
- Their browser has cached data
- Sync hasn't completed

**Solutions**:
1. Ask them to refresh page
2. Clear their browser cache
3. Wait a minute for sync

---

## Conflicts Between Devices

If same record edited on two devices:

1. Most recent edit usually wins
2. Check which version is there
3. Re-enter if your change was lost
4. Avoid editing same record simultaneously

---

## Slow Sync

If sync takes very long:

1. Check internet speed
2. Avoid large bulk operations
3. Sync during off-peak hours if possible
4. Contact support if always slow

---

## After Long Offline Period

When coming back online after hours/days:

1. Let sync complete fully first
2. Don't make changes during sync
3. Verify recent data after sync
4. Check for any conflict notices

---

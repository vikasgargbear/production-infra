# 🔧 Common Errors & Solutions

> Quick fixes for common issues you might encounter.

---

## Login Issues

### "Invalid username or password"

**Possible causes**:
- Typing error in username or password
- Caps Lock is on
- Password was changed

**Solutions**:
1. Check for typing errors carefully
2. Make sure Caps Lock is off
3. Try with correct capitalization
4. Click "Forgot Password" to reset

---

### "Account locked"

**Why it happens**: Too many failed login attempts

**Solution**:
1. Wait 15 minutes and try again
2. Or contact admin to unlock your account
3. Use "Forgot Password" to reset

---

### "Session expired"

**Why it happens**: You were inactive for too long

**Solution**:
1. Log in again
2. This is normal security behavior
3. Save work frequently to avoid data loss

---

## Invoice Issues

### "Cannot save invoice - Customer required"

**Solution**: Select a customer before saving. Use "Walk-in Customer" for anonymous sales.

---

### "Cannot save invoice - No items added"

**Solution**: Add at least one product to the invoice before saving.

---

### "Product not found"

**Possible causes**:
- Product not added to system
- Spelling error in search

**Solutions**:
1. Check spelling and try again
2. Add the product first in **Inventory → Add Product**
3. Try searching by barcode or product code

---

### "Batch not available" or "Insufficient stock"

**Why it happens**: The product doesn't have enough stock

**Solutions**:
1. Check available quantity in Current Stock
2. Reduce the quantity on the invoice
3. Select a different batch
4. Add new stock through purchase

---

## Print Issues

### "Print preview not loading"

**Solutions**:
1. Wait a few seconds for loading
2. Refresh the page
3. Try a different browser
4. Clear browser cache

---

### "Printer not printing"

**Solutions**:
1. Check printer is turned on and connected
2. Check for paper and ink
3. Try printing a test page from your computer
4. Restart the printer
5. Check printer settings in browser

---

### "Print layout is wrong"

**Solutions**:
1. Go to **Settings → Print Templates**
2. Select the correct paper size
3. Check print margins in your browser/printer settings
4. Adjust print scale if needed (100% recommended)

---

### "Changes not saving"

**Solutions**:
1. Check internet connection
2. Retry the canonical API action
3. Don't navigate away before save completes
4. Look for the fail-closed API error and request identifier

---

## Performance Issues

### "Application is slow"

**Quick fixes**:
1. Refresh the page
2. Close other browser tabs
3. Clear browser cache
4. Try a different browser (Chrome recommended)

**If issue persists**:
1. Check your internet speed
2. Restart your device
3. Contact support

---

### "Page not loading"

**Solutions**:
1. Refresh the page
2. Check internet connection
3. Clear browser cache
4. Try incognito/private mode
5. Try a different browser

---

## Data Issues

### "Invoice showing wrong amount"

**Check**:
1. Product prices are correct
2. Quantities are correct
3. Discounts are applied correctly
4. GST rates are correct

**Solution**: If invoice is draft, edit and correct. If confirmed, cancel and create new.

---

### "Stock count is wrong"

**Steps**:
1. Check recent transactions for errors
2. Verify purchase GRNs were completed
3. Check for unsaved sales
4. Do a stock adjustment to correct

---

### "Customer data missing"

**Solutions**:
1. Search by phone number instead of name
2. Check if customer was accidentally deleted
3. Re-add the customer if needed

---

## Error Messages

### "Something went wrong"

**General solution**:
1. Refresh the page
2. Try the action again
3. If it persists, note what you were doing
4. Contact support with details

---

### "Permission denied"

**Why**: You don't have access to this feature

**Solution**: Contact your admin to get the required permission.

---

### "Server error" or "500 error"

**Why**: Server-side issue

**Solutions**:
1. Wait a few minutes and try again
2. This is usually temporary
3. If persists, contact support

# 🔄 Purchase Returns

> Learn how to return goods to suppliers.

---

## When to Return

Return goods to suppliers when:
- Products are damaged on arrival
- Wrong items were sent
- Products are expired
- Quality doesn't meet standards
- Excess quantity received

---

## Creating a Purchase Return

### Step 1: Start Return

1. Go to **Purchase → Purchase Returns**
2. Click **New Return**
3. Or from GRN: Click **Create Return**

### Step 2: Select Reference

Choose what you're returning against:
- **Against GRN** - Specific receipt
- **Against Supplier** - General return

### Step 3: Select Items

1. Check items being returned
2. Enter **Return Quantity**
3. Select **Reason**:
   - Damaged
   - Expired
   - Wrong Item
   - Quality Issue
   - Excess Quantity

### Step 4: Add Details

- **Return Date** - Date of return
- **Notes** - Additional information
- **Transport** - If shipping back

### Step 5: Save Return

1. Review items and quantities
2. Click **Save Return**
3. Print return note if needed

---

## What Happens After?

| Action | Effect |
|--------|--------|
| **Stock** | Reduced by return quantity |
| **Outstanding** | Reduced (you owe less) |
| **Debit Note** | Generated for supplier |

---

## Return Status

| Status | Meaning |
|--------|---------|
| **Draft** | Not yet processed |
| **Confirmed** | Return processed |
| **Settled** | Supplier adjusted payment |

---

## Sending Returns to Supplier

After creating return:

1. Print the **Debit Note**
2. Pack the return items
3. Send with transport
4. Follow up with supplier for:
   - Replacement, OR
   - Credit note, OR
   - Refund

---

## Common Questions

### Does return affect what I owe?
Yes, your payable decreases by return amount.

### What about already paid items?
Creates a credit balance with supplier. Applied to next purchase.

### Can I return partial quantity?
Yes, enter only the quantity being returned.

### What if supplier refuses return?
Document it. May need to write off or adjust stock.

---

## Best Practices

✅ **Return quickly** - Most suppliers have time limits  
✅ **Document damage** - Take photos if needed  
✅ **Keep transport proof** - For valuable returns  
✅ **Follow up** - Ensure supplier acknowledges

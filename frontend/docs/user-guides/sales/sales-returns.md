# 🔄 Sales Returns

> Learn how to process customer returns and issue credit notes.

---

## When to Use Sales Returns

Use the Sales Return feature when:

- Customer returns purchased items
- Items are damaged or defective
- Wrong items were delivered
- Customer cancelled the order
- Goods expired before use

---

## Step 1: Start a Sales Return

**Option A**: From Original Invoice
1. Go to **Sales → Invoice History**
2. Find the original invoice
3. Click **Create Return**

**Option B**: From Menu
1. Go to **Sales → Sales Returns → New Return**
2. Search and select the original invoice

---

## Step 2: Select Items to Return

You'll see all items from the original invoice:

1. Check the box next to items being returned
2. Enter the **Return Quantity** (can be partial)
3. Select a **Reason** for return:
   - Damaged/Defective
   - Wrong Item
   - Customer Changed Mind
   - Expired Product
   - Other

> 💡 **Tip**: You can return some items while keeping others.

---

## Step 3: Choose Return Type

How do you want to handle the return?

| Option | When to Use |
|--------|-------------|
| **Credit Note** | Reduce customer's outstanding |
| **Cash Refund** | Give cash back to customer |
| **Replacement** | Exchange for other items |

### Credit Note
- Amount is deducted from customer's account
- Applied to future invoices
- No cash changes hands

### Cash Refund
- You return cash to customer
- Select payment method for refund
- Records the outgoing payment

### Replacement
- Process the return
- Create new invoice for replacement items
- Only charge difference (if any)

---

## Step 4: Review Return Details

Before confirming, review:

- **Items**: Correct items and quantities
- **Amounts**: Return value calculated correctly
- **Reason**: Proper reason selected
- **Stock**: Items will be added back to inventory

---

## Step 5: Save Return

1. Click **Process Return** or **Save**
2. Credit note/refund is created
3. Stock is updated automatically
4. Customer account is adjusted

---

## After Processing

### Print Credit Note
- Click **Print** to give customer a copy
- Or share via WhatsApp

### Check Stock
- Returned items are added back
- Check in **Inventory → Current Stock**

### View Return History
- Go to **Sales → Sales Returns**
- See all processed returns

---

## Partial Returns

You don't have to return everything:

**Example**:
- Original Invoice: 10 tablets, 5 syrups
- Customer returns: Only 3 tablets
- Process return for 3 tablets only

---

## Returns for Credit Customers

When a credit customer returns items:

1. Process return as **Credit Note**
2. Amount is deducted from their outstanding
3. No cash payment needed

**Example**:
- Customer outstanding: ₹5,000
- Return value: ₹500
- New outstanding: ₹4,500

---

## Common Questions

### Can I return items from old invoices?
Yes, you can create returns for any invoice within your return policy period.

### What if item is not saleable?
Process the return normally. Damaged items go back to stock but can be marked as damaged during stock adjustment.

### How do refunds work for card payments?
Card refunds must be processed through your payment terminal. The system records the refund for your records.

### Can I cancel a sales return?
Returns should not be cancelled once processed. Create an adjustment if needed.

### What about partial quantity returns?
Fully supported. Enter the quantity being returned (even if less than original).

---

## Best Practices

✅ **Always verify items** before processing return  
✅ **Check expiry dates** on returned medicines  
✅ **Document reason** for future reference  
✅ **Print credit note** for customer's records  
✅ **Review damaged items** before restocking

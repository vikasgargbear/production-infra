# 📦 Delivery Challan

> Send goods without creating an invoice using delivery challan.

---

## What is a Delivery Challan?

A **Delivery Challan** is a document used when you send goods without billing. The invoice is created later.

---

## When to Use Challan

Use delivery challans when:
- Sending goods for approval (sale on approval)
- Transferring between branches
- Sending demo or sample products
- Goods are billed later after delivery
- For job work or processing

---

## Creating a Delivery Challan

### Step 1: Start Challan

1. Go to **Sales → New Challan**
2. Or from Dashboard → **Create Challan** quick action

### Step 2: Select Customer

1. Search and select the customer
2. Their delivery address auto-fills

### Step 3: Add Items

1. Search for products
2. Select batch if required
3. Enter quantity
4. Add more items as needed

### Step 4: Transport Details

Fill in delivery information:
- **Transport Name** - Carrier/courier
- **Vehicle Number** - If applicable
- **LR Number** - Lorry receipt number
- **Delivery Date** - Expected delivery

### Step 5: Delivery Address

Confirm or edit the delivery address:
- Can be different from billing address
- Enter complete address with pincode

### Step 6: Save Challan

1. Review all details
2. Click **Save Challan**
3. Print or share with customer

---

## Converting Challan to Invoice

When goods are accepted:

1. Go to **Sales → Challans**
2. Find the challan
3. Click **Convert to Invoice**
4. Review and adjust if needed
5. Invoice is created

---

## Challan Status

| Status | Meaning |
|--------|---------|
| **Draft** | Not yet sent |
| **Sent** | Goods dispatched |
| **Partially Invoiced** | Some items billed |
| **Fully Invoiced** | All items billed |
| **Cancelled** | Challan cancelled |

---

## Printing Challan

Challan prints include:
- Company details
- Customer and delivery address
- Item list with quantities
- Transport details
- Signature space for receiver

---

## Common Questions

### Does challan affect stock?
Yes, stock is reduced when challan is created (as goods are sent out).

### What if customer rejects goods?
Create a return for rejected items. Stock comes back.

### GST on challans?
Challans don't have GST - it's on the invoice. But E-way bill may still be needed for transport.

### How long can goods remain on challan?
Best practice is to invoice within 30 days. Check GST rules for compliance.

---

## Best Practices

✅ **Clear transport details** - For tracking  
✅ **Get receiver signature** - On printed copy  
✅ **Invoice promptly** - Don't keep pending too long  
✅ **Track pending challans** - Regular review

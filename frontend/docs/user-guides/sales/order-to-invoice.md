# 📋 Converting Order to Invoice

> Learn how to convert a sales order into an invoice.

---

## What is a Sales Order?

A **Sales Order** is a confirmed order from a customer that's not yet invoiced. It reserves stock and commits to the sale, but billing happens later.

---

## When to Use Orders

Use sales orders when:
- Customer orders for future delivery
- You need to reserve stock
- Delivery date is different from order date
- You need manager approval before invoicing

---

## Creating a Sales Order

1. Go to **Sales → New Order**
2. Select customer
3. Add products (same as invoice)
4. Set delivery date
5. Save as **Sales Order**

---

## Converting Order to Invoice

### Step 1: Find the Order

1. Go to **Sales → Sales Orders**
2. Find the order you want to convert
3. Click on the order

### Step 2: Review Order

Check the order details:
- Customer is correct
- Items and quantities are right
- Prices are still valid

### Step 3: Convert

1. Click **Convert to Invoice** button
2. Confirm the action
3. Invoice is created with same details

### Step 4: Complete Invoice

You can now:
- Accept payment
- Print the invoice
- Share with customer

---

## Partial Conversion

If only part of the order is ready:

1. Open the sales order
2. Click **Convert to Invoice**
3. Adjust quantities to what's being delivered
4. Remaining qty stays as pending order

---

## Order Status

| Status | Meaning |
|--------|---------|
| **Draft** | Order saved but not confirmed |
| **Confirmed** | Order is active |
| **Partially Invoiced** | Some items converted |
| **Fully Invoiced** | All items invoiced |
| **Cancelled** | Order was cancelled |

---

## Common Questions

### Can I edit an order after creating it?
Yes, draft and confirmed orders can be edited. Once invoiced, changes require new transactions.

### What happens to stock when I create an order?
Stock is "reserved" - it shows as allocated but not sold yet.

### Can I add items during conversion?
Yes, you can add more items when converting to invoice.

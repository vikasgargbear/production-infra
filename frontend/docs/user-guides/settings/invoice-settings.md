# 🧾 Invoice Settings

> Customize how your invoices work.

---

## Accessing Invoice Settings

1. Go to **Settings → Invoice Settings**
2. Configure your preferences

---

## Invoice Numbering

Control how invoices are numbered:

| Setting | Description |
|---------|-------------|
| **Prefix** | Text before number (e.g., "INV-") |
| **Starting Number** | First invoice number |
| **Format** | Number format (with year, etc.) |

### Examples
- Simple: `INV-001, INV-002...`
- With Year: `INV-2024-001`
- With Branch: `DEL-INV-001`

---

## Default Values

Pre-fill common values:

| Setting | Description |
|---------|-------------|
| **Payment Terms** | Default days for due date |
| **Terms & Conditions** | Default T&C text |
| **Notes** | Default internal notes |
| **Salesperson** | Auto-assign to seller |

---

## Tax Settings

| Setting | Description |
|---------|-------------|
| **Default GST Rate** | For new products |
| **Include Tax in Price** | Tax-inclusive pricing |
| **Show Tax Breakdown** | Display CGST/SGST on invoice |

---

## Discount Settings

| Setting | Description |
|---------|-------------|
| **Maximum Discount** | Limit on discounts |
| **Require Approval** | Manager approval for high discount |
| **Discount on MRP** | Allow MRP discount |

---

## Billing Options

| Setting | Description |
|---------|-------------|
| **Round Off** | Round total to nearest rupee |
| **Allow Credit Sales** | Enable credit/due sales |
| **Credit Limit Check** | Block if limit exceeded |
| **Negative Stock** | Allow sales without stock |

---

## Print Settings

| Setting | Description |
|---------|-------------|
| **Auto Print** | Print on save |
| **Print Copies** | Number of copies |
| **Default Size** | Thermal, A5, A4 |

---

## Saving Settings

1. Make your changes
2. Click **Save**
3. Settings apply to new invoices

> ⚠️ Changes don't affect existing invoices.

---

## Common Questions

### Can I change invoice prefix mid-year?
Yes, but maintain consistency for accounting. Consider year prefix.

### How do I reset number sequence?
Change starting number in settings. Usually done at year start.

### Where do I set GST rates?
Individual product GST is set in product settings. Default is here.

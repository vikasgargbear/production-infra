# 👥 User Management

> Add team members and manage access.

---

## Overview

User management lets you:
- Add new users (staff, managers)
- Set roles and permissions
- Control who can access what
- Deactivate users who leave

---

## Accessing User Management

1. Go to **Settings → User Management**
2. View all users in your organization

---

## Adding a New User

### Step 1: Click Add User
1. Go to **Settings → User Management**
2. Click **+ Add User**

### Step 2: Enter Details
- **Name** - User's full name
- **Email** - For login and notifications
- **Phone** - Mobile number
- **Role** - Select from available roles

### Step 3: Set Role
Choose user's role:
- **Admin** - Full access to everything
- **Manager** - Sales, purchase, reports
- **Salesperson** - Create invoices only
- **Accountant** - Finance and reports
- **Viewer** - View only, no edits

### Step 4: Save
1. Click **Save**
2. User receives login credentials
3. They can now access the system

---

## User Roles Explained

| Role | Can Do |
|------|--------|
| **Admin** | Everything - full control |
| **Manager** | Sales, purchase, inventory, reports |
| **Salesperson** | Create invoices, view products |
| **Accountant** | Payments, ledger, reports |
| **Viewer** | View data only, no changes |

---

## Editing Users

1. Find the user in the list
2. Click **Edit** icon
3. Update required fields
4. Save changes

---

## Deactivating Users

When someone leaves:

1. Find the user
2. Click **Deactivate** (not delete)
3. User can no longer log in
4. Their data/history is preserved

> 💡 **Tip**: Deactivate rather than delete to maintain records.

---

## Resetting Password

If user forgot password:

### Method 1: User Self-Reset
- User clicks "Forgot Password" on login
- Receives reset link via email

### Method 2: Admin Reset
1. Find user in list
2. Click **Reset Password**
3. New temporary password is sent

---

## Common Questions

### How many users can I add?
Depends on your subscription plan. Check your plan details.

### Can users have multiple roles?
Typically one role per user. Contact support for custom permissions.

### What happens to user's data when deactivated?
All data remains. Reassign if needed.

### Can I see who did what?
Check the audit log for user activities.

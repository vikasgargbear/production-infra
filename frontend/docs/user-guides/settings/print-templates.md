# 🖨️ Print Templates

> Customize how your documents look when printed.

---

## Accessing Print Templates

1. Go to **Settings → Print Templates**
2. View and customize templates

---

## Available Templates

| Template | Used For |
|----------|----------|
| **Invoice - Thermal** | Small receipt printers |
| **Invoice - A4** | Full page invoices |
| **Invoice - A5** | Half page invoices |
| **Challan** | Delivery challans |
| **Purchase Order** | PO printouts |
| **Receipt** | Payment receipts |

---

## Template Settings

### Paper Size
- Thermal 2" (58mm)
- Thermal 3" (80mm)
- A5 (148 × 210 mm)
- A4 (210 × 297 mm)

### Header Options
- **Show Logo** - Display company logo
- **Show Company Name** - Business name
- **Show Address** - Full address
- **Show GST Number** - GSTIN
- **Show Contact** - Phone/email

### Body Options
- **Show HSN Code** - HSN on each item
- **Show Batch/Expiry** - Batch details
- **Show Tax Breakdown** - CGST/SGST columns
- **Show MRP** - Maximum retail price
- **Show Discount** - Discount column

### Footer Options
- **Show Bank Details** - For payments
- **Show Terms** - Terms & conditions
- **Show Signature** - Signature space
- **Show Thank You** - Thank you message

---

## Setting Default Template

1. Choose the template
2. Click **Set as Default**
3. This template prints automatically

---

## Preview Template

Before saving:
1. Make changes
2. Click **Preview**
3. See how it looks
4. Adjust if needed
5. Save

---

## Custom Footer Text

Add your own text:
- Thank you message
- Return policy
- Contact info
- Promotional message

---

## Common Questions

### Print looks different on my printer?
Check printer settings - margins, paper size, and scaling.

### How do I add QR code?
Enable UPI QR in Settings for payment QR code.

### Can I have different templates for GST/non-GST?
Yes, create separate templates for different purposes.

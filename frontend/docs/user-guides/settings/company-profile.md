# 🏢 Company Profile

> Set up your business information.

---

## What is Company Profile?

Your company profile contains business information that appears on:
- Invoices and receipts
- Purchase orders
- All printed documents
- GST returns

---

## Accessing Company Profile

1. Go to **Settings → Company Profile**
2. View and edit your details

---

## Basic Information

| Field | Description |
|-------|-------------|
| **Business Name** | Your company/shop name |
| **Trade Name** | Trading name (if different) |
| **Legal Name** | Registered legal name |

---

## Contact Details

| Field | Description |
|-------|-------------|
| **Phone** | Primary business phone |
| **Email** | Business email address |
| **Website** | Company website (optional) |
| **Address** | Complete business address |
| **City** | City name |
| **State** | State/Province |
| **PIN Code** | Postal code |

---

## Tax Information

| Field | Description |
|-------|-------------|
| **GSTIN** | GST Identification Number |
| **PAN** | Permanent Account Number |
| **Drug License** | DL Number (for pharma) |
| **FSSAI** | Food license (if applicable) |

---

## Bank Details

For invoices and payment collection:

| Field | Description |
|-------|-------------|
| **Bank Name** | Your bank |
| **Account Number** | Bank account number |
| **IFSC Code** | Bank branch IFSC |
| **Account Name** | Name on account |
| **UPI ID** | For UPI payments |

These appear on invoices for customer payments.

---

## Company Logo

Add your logo:

1. Click **Upload Logo**
2. Select image file (PNG, JPG)
3. Recommended size: 300x100 pixels
4. Logo appears on all documents

---

## Saving Changes

1. Update the required fields
2. Click **Save Changes**
3. Changes apply immediately

---

## Common Questions

### Why isn't my logo showing on invoices?
Check if logo was uploaded successfully. Also verify print template includes logo.

### How do I update GST number?
Edit the GSTIN field. If registered number changed, you may need additional documentation.

### Can I change business name?
Yes, edit the name field. For official name changes, ensure legal documents are updated.

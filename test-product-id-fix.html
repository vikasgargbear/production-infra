🔧 Fixed: Product ID Integer Overflow Error

❌ The Problem

Error: "integer out of range" when creating purchase with new products

psycopg2.errors.NumericValueOutOfRange: integer out of range [parameters: {'product_id': 1756880931076, ...}]

Why it happened:

Value Type Example Value Status
Date.now() timestamp 1756880931076 ❌ Too large for INTEGER
PostgreSQL INTEGER max 2,147,483,647 ✅ Maximum allowed

The frontend was using Date.now() to generate temporary IDs for new products, but these timestamp values are too large for PostgreSQL INTEGER columns.

✅ The Solution

1. Fixed Frontend Code

File: EnhancedPurchaseEntry.js (line 210)

Before (Incorrect):

product_id: product.product_id || product.id || null, // Bug: product.id might be Date.now()

After (Fixed):

product_id: product.product_id || null, // Only use proper product_id, not id field

2. How the Backend Handles New Products

When product_id is null but product_name is provided:

  1. Backend checks if product already exists (by name)
  2. If found → uses existing product_id
  3. If not found → creates new product with proper ID
# Backend logic (purchase_enhanced.py): if not product_id and product_name: # Check for existing product existing = db.execute("SELECT product_id FROM products WHERE name = ?", product_name) if existing: product_id = existing.product_id else: # Create new product with backend-generated ID new_product = create_product(product_name) product_id = new_product.product_id # Proper ID from database

✨ Result

New products are now created properly!

  • ✅ Frontend sends product_id: null for new products
  • ✅ Backend creates product with valid ID
  • ✅ No more integer overflow errors
  • ✅ Purchase creation works smoothly

Technical Details

Root Cause: The id field (used for UI row tracking) was being mistakenly used as a fallback for product_id

Fix Applied: Removed product.id from the fallback chain, ensuring only valid product_id values are used

Backend Behavior: Already handles null product_ids correctly by creating new products when needed
